A note on interpretation

Influence ratings are hypotheses, not ground truth. Results measure prompted model behaviour—not human preferences or cultural traits. Empty and low-salience controls help separate genuine context effects from the model’s baseline distribution.

How to read this atlas

Exact-label diversity treats “blue” and “midnight blue” separately. Broad-hue diversity groups perceptually related answers. Distance is total variation from the selected baseline distribution. Findings describe this model under these prompts—not people, cultures, or universal colour preferences.

ABOUT THE LAB

Small prompts, measurable shifts.

Every observation is a brand-new Responses API call: no previous response ID, no conversation history, and no awareness of other trials.

  • Contexts and hypotheses live in data/contexts.json.
  • Run metadata is stored as JSON; observations append safely to JSONL.
  • Your API key is never included in either file.
